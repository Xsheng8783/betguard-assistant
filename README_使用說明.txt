========================================
  Betguard Assistant — 安裝與使用說明
  本地審核台 + 輔助填入工具
========================================

本工具輔助人工核對牌單、自動填入真站號碼與金額。
不會自動送出、不會自動確認——最後送出永遠要由使用者手動操作。

═══════════════════════════════════════════
  第一次安裝（只需做一次）
═══════════════════════════════════════════

1. 安裝 Python 3.11 以上
   https://www.python.org/downloads/
   安裝時勾選 "Add Python to PATH"

2. 開啟命令提示字元（PowerShell 或 cmd），進入本資料夾：
   cd 複製過來的\betguard-assistant

3. 建立虛擬環境（可選，建議）：
   python -m venv .venv
   然後啟動：
   .venv\Scripts\activate

4. 升級 pip 並安裝專案：
   python -m pip install --upgrade pip
   python -m pip install -e .
   python -m pip install playwright pytest

5. 安裝 Playwright 瀏覽器：
   python -m playwright install chromium

═══════════════════════════════════════════
  每日使用
═══════════════════════════════════════════

1. 雙擊 start_betguard.bat
   → 會自動啟動本地 server 並打開瀏覽器
   → 網址：http://127.0.0.1:8765

2. 在 Web UI 中貼上牌單 → 建立審核批次

3. 按「開啟下牌網站」→ 手動登入 gts362.com
   → 手動切到對應遊戲（539 或天天樂）
   → 二三四星 → 連碰（一般牌）或住碰／柱碰頁

4. 從「待輔助填入」列表按「輔助填入」
   → 系統只會填入號碼與金額，不送出

5. 每次填完後人工檢查頁面：
   - 號碼正確？
   - 金額正確？
   - 確認後才手動點「送出」

═══════════════════════════════════════════
  重要安全提醒
═══════════════════════════════════════════

⚠️ 本工具不會自動送出、不會自動確認。
   所有「送出注單」必須由操作者人工點擊。

⚠️ 不適合自動掛機或大量連續下注。

⚠️ 輔助填入後請務必人工檢查頁面再送出。

═══════════════════════════════════════════
  如果出錯
═══════════════════════════════════════════

1. 截圖錯誤畫面（Print Screen 或 Snipping Tool）
2. 複製 server 視窗（黑色 cmd 視窗）中的錯誤訊息
3. 連絡技術支援，附上：
   - 錯誤畫面截圖
   - server log 文字
   - 正在處理的牌單原文
