# Betguard Assistant - 快速上手（給不懂電腦的人）

## 第一次使用（只需要做一次）

1. 找到資料夾裡的 `scripts` 資料夾
2. 點兩下 `install_or_repair.bat`
3. 等它跑完（會出現「安裝完成」）
4. 關掉那個黑黑的視窗

## 每次要用 Betguard 的時候

1. 找到資料夾裡的 `scripts` 資料夾
2. 點兩下 `start_betguard.bat`
3. 瀏覽器會自動打開 Betguard 頁面
4. 黑黑的視窗**不要關掉**，那是 Betguard 在運作

## 操作步驟

### 第一步：貼牌
- 在 Betguard 頁面的大框框貼上客人傳來的牌單（LINE、聊天室的文字）
- 遊戲類型選「自動判斷」就好
- 按「建立審核批次」

### 第二步：開啟下牌網站
- 會跳到審核頁面
- 按最上面的「🌐 開啟下牌網站」
- 會跳出一個新的瀏覽器視窗（下牌網站）
- 在這個新視窗**手動登入你的帳號**
- 登入後，點到「539」或「天天樂」的「二三四星」頁面

### 第三步：輔助填入
- 回到 Betguard 審核頁面
- 找到你要下注的那一筆（正確候選那邊）
- 按「輔助填入」
- 會跳出預覽，確認號碼和金額沒錯
- 按「開始輔助填入」
- Betguard 會自動在下牌網站幫你點號碼、填金額

### 第四步：人工檢查並送出
- **Betguard 不會幫你按送出！**
- **Betguard 不會幫你按確認！**
- 你要自己回到下牌網站視窗
- 人工檢查號碼和金額是否正確
- 確認無誤後，**自己手動按送出／確認**

## ⚠️ 重要提醒

- Betguard **只會填號碼和金額**，不會自動下注
- 送出和確認**一定要你自己按**
- 如果你的下牌網站帳號需要登入，**你自己手動登入**
- Betguard **不會記錄你的帳號密碼**
- 如果出現紅色錯誤訊息，**截圖給我**

## 第二筆以後

- 不用再按「開啟下牌網站」
- 直接按下一筆的「輔助填入」→「開始輔助填入」即可
- Betguard 會重用同一個下牌網站視窗

## 關閉

- 下牌網站視窗可以自己關
- Betguard 的黑窗按 Ctrl-C 關閉
- 或直接關掉黑窗

## 遇到問題？

1. 截圖
2. 把黑窗裡面的紅字也截下來
3. 傳給我
